# ITU Blockchain Devs komitesi I. proje:Chaincon


Projeyi kendi bilgisayarınızda çalıştırmak için aşağıdaki adımları izleyin:

1.  **Projeyi İndirin:**
    ```bash
    git clone [https://github.com/Allie198/Chaincon.git](https://github.com/Allie198/Chaincon.git)
    cd Chaincon
    ```

2.  **Gerekli Paketleri Yükleyin:**
    Proje `inquirer` gibi harici kütüphaneler kullandığı için NPM paketlerini yüklemeniz gerekir:
    ```bash
    npm install
    ```

3.  **Uygulamayı Başlatın:**
    ```bash
    node cli.js
    ```
